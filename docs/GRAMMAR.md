# Grammar: тест уровня и уроки

Общий раздел: открыт всем разрешённым аккаунтам с главного экрана, профиль
не нужен. В разделе две вкладки:

- **Test** (`grammar.html`, открывается по умолчанию) — тест, который показывает
  примерный уровень грамматики по шкале CEFR, от A1 до C2;
- **Learn** (`grammar.html?tab=learn`) — уроки грамматики. Пока там пусто,
  материалы добавим позже, тоже в папку `grammar/`.

Все материалы лежат в проекте: Supabase, ИИ и отдельные маршруты Worker
не используются. Worker только принимает отчёт так же, как для Test.

Тест проверяет только грамматику, а не разговор, понимание на слух или запас
слов. Поэтому результат — это уровень грамматики, а не общий уровень языка.

## Как проходит тест

- Вопросы идут блоками по уровням: A1 → A2 → B1 → B2 → C1 → C2, по 8 в каждом,
  всего до 48. Внутри блока вопросы и варианты ответов каждый раз перемешиваются.
- В каждом вопросе предложение с пропуском, четыре варианта и кнопка
  **I don't know**. Она засчитывается как ошибка и нужна, чтобы не угадывать.
- Во время теста не видно, правильный ли ответ: нажатие только отмечается,
  и через четверть секунды появляется следующий вопрос.
- Уровень засчитан при 6 и более правильных из 8. Тест останавливается на первом
  незасчитанном уровне: дальше вопросы только сложнее. Новичок закончит
  за 8–16 вопросов, сильный пройдёт все 48 примерно за 15–20 минут.
- Итог — последний засчитанный уровень. Если на следующем было 5 из 8, к итогу
  добавляется «close to …». Если не засчитан даже A1, итог **Pre-A1 (Starter)**.
- Правила (8 вопросов на уровень, порог 6) заданы в `assets/js/grammar-core.js`.

## Экран результата и отчёт

Человек видит свой уровень, результат по каждому пройденному уровню и разбор
ошибок: предложение с правильным ответом, свой ответ и короткое пояснение
по-украински. Кнопки: **Take the test again** и **Finish**.

Каждое завершение теста отправляется в бот, в `CHAT_ID`, через общий
`sendReport`, как результаты Test. Профиля у раздела нет, поэтому строки
«Учень:» в отчёте нет: кто проходил тест, видно по имени Telegram в заголовке,
которое Worker берёт из подписанных данных запуска.

```text
🧩 Граматика — Олег Петренко (@oleg)

Рівень граматики: B1 (Intermediate), близько до B2
A1 8/8 · A2 7/8 · B1 6/8 · B2 5/8
Відповідей: 32 · час: 11 хв
Над чим попрацювати: Past perfect; Third conditional
```

«Над чим попрацювати» — темы вопросов с ошибкой или «I don't know», без
повторов. Если ошибок нет, в отчёте будет «Помилок немає». Если отправить
не удалось, на экране появляется **Send again**. Если Worker отказывает
аккаунту, страница закрывается зонтиком, как и другие разделы. Тест, открытый
не через бота, отчёт отправить не может.

## Файл с вопросами

Вопросы лежат в `grammar/level-test.json`: это массив, по 8 вопросов на каждый
уровень, в любом порядке.

```json
{ "level": "B1", "topic": "Present perfect with for / since",
  "q": "I ___ here since 2019.", "right": "have lived", "wrong": ["live", "am living", "lived"],
  "explain": "Since + момент у минулому, дія триває досі → present perfect: have lived." }
```

| Поле | Что в нём |
| --- | --- |
| `level` | `A1`, `A2`, `B1`, `B2`, `C1` или `C2` |
| `topic` | Тема по-английски. Попадает в «Над чим попрацювати». |
| `q` | Предложение ровно с одним пропуском `___` |
| `right` | Правильный ответ |
| `wrong` | Ровно три неправильных ответа. Все четыре варианта должны различаться. |
| `explain` | Короткое пояснение по-украински для разбора ошибок |

Если файл нарушает эти правила, страница показывает «Could not load» и номер
вопроса, который надо поправить. У каждого вопроса должен быть ровно один
правильный ответ: не используй варианты, которые тоже верны в британском или
американском английском или при другом прочтении предложения.

Все вопросы написаны для этого проекта и не скопированы из чужих тестов.

## Ограничения

- Вопросы одни и те же для всех, поэтому результаты можно сравнивать.
  Повторная попытка проходит легче, так что показательнее первая.
- Прогресс не сохраняется: если обновить страницу во время теста, он начнётся
  заново.
- Файл с ответами публичный, как и остальные файлы GitHub Pages.

## Проверки и публикация

```sh
node --test tests/grammar.test.cjs
```

Тесты проверяют файл с вопросами, подсчёт уровня, текст отчёта и работу
страницы. После изменения `assets/js/grammar*.js` или `assets/css/grammar.css`
подними их `?v=` в `grammar.html`, иначе Telegram может взять старые файлы
из кеша. Изменение одного только `grammar/level-test.json` версии не требует:
он загружается без кеша.
