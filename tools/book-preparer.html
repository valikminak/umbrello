EPUB → JSON

Подготовка английской книги для Umbrello. Выбери EPUB с компьютера — обработка происходит здесь, без загрузки файла на сервер.

Файл не выбран

Сначала преобразуй книгу, затем скачай JSON или скопируй отдельный абзац.

bookId:

    Фрагмент JSON

    Выбери абзац, чтобы скопировать его для обсуждения. Скачиваемый файл выше содержит книгу целиком.

    Что находится в JSON
    • Главы, абзацы, предложения и их полный текст.
    • У каждого слова: уникальный id, общий key и границы start / end внутри предложения.
    • text.slice(start, end) даёт исходное слово. Конец диапазона не включается; смещения — UTF-16, как в JavaScript.
    • Регистр, варианты апострофов и дефисов нормализуются только в key. Разные формы слова не объединяются.
    • Формат 2, без готовых страниц по 300 слов. Вывод этого формата в Books будет следующим этапом.
