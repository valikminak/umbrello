# Локальные инструменты

## EPUB → JSON

Открой `book-preparer.html` в браузере с компьютера. Python, сервер и интернет
для обработки не нужны; HTML должен оставаться рядом с JS-файлами и папкой `vendor/`.

1. Нажми **Открыть EPUB** и выбери английскую книгу без DRM.
2. После обработки появятся название, автор, количество разделов, абзацев,
   предложений и слов, размер результата и замечания, если они возникли.
3. **Скачать JSON** сохраняет всю книгу в компактном формате.
4. Чтобы поделиться частью результата, выбери раздел и абзац, затем нажми
   **Скопировать фрагмент**. Этот фрагмент помечен `sample: true` и не заменяет полную книгу.

Это только конвертер. Просмотра книги, запросов к ИИ и загрузки в Storage здесь нет.
EPUB и его текст не отправляются на сервер и не сохраняются в localStorage.

### Формат 2

Новый файл имеет `formatVersion: 2`. Читалка Books принимает форматы 1 и 2
и раскладывает текст по экрану телефона. Старый `prepare-book.py` продолжает
создавать формат 1 и не изменён; его поле `pages` не задаёт страницы в Mini App.

Пример структуры новой книги:

```json
{
  "formatVersion": 2,
  "bookId": "<SHA-256 подготовленного содержимого, 64 hex-символа>",
  "title": "Example",
  "author": "Author",
  "language": "en",
  "processing": {
    "version": 1,
    "sentenceSplitter": "sbd-1.0.19+umbrello-1",
    "wordTokenizer": "umbrello-1",
    "offsetUnit": "utf16"
  },
  "stats": {
    "chapters": 1,
    "paragraphs": 1,
    "sentences": 1,
    "words": 3,
    "uniqueWords": 3
  },
  "chapters": [
    {
      "id": "c1",
      "title": null,
      "paragraphs": [
        {
          "id": "c1.p1",
          "kind": "text",
          "sentences": [
            {
              "id": "c1.p1.s1",
              "text": "He gave up.",
              "words": [
                {"id": "w1", "key": "he", "start": 0, "end": 2},
                {"id": "w2", "key": "gave", "start": 3, "end": 7},
                {"id": "w3", "key": "up", "start": 8, "end": 10}
              ]
            }
          ]
        }
      ]
    }
  ]
}
```

- Порядок массивов — порядок чтения. Готового массива экранных страниц нет.
- Заголовки включены в поток текста как абзацы с `kind: "heading"` и `level: 1…6`.
  `chapter.title` — метаданные раздела; при будущем выводе не нужно добавлять
  ещё один заголовок, если он уже есть среди абзацев.
- `sentence.text` хранит предложение целиком, с пунктуацией. Пробел между
  соседними предложениями в одном абзаце восстанавливается через `join(" ")`.
- `word.id` (`w1`, `w2`, …) — уникальное вхождение в пределах книги, в порядке чтения.
  Связь с предложением, абзацем и главой задаёт вложенность JSON. Этот ID подходит
  для позиции чтения и указания нажатого слова.
- `word.key` — общий ключ одинаковых слов. Здесь приводятся к нижнему регистру
  буквы, к обычному апострофу — `’` и `ʼ`, к обычному дефису — `‐` и `‑`.
  Мягкий перенос удаляется из ключа. Исходный `sentence.text` при этом не меняется.
  Формы `give`, `gave`, `given` остаются разными ключами.
- `start` включается, `end` не включается. Смещения — кодовые единицы UTF-16:
  `sentence.text.slice(word.start, word.end)` возвращает исходное слово.
  Не нужно считать позиции по байтам или Unicode code points.
- Сокращения с апострофом и слова с внутренним дефисом представлены одним токеном.
  Числа также получают ID; отдельная пунктуация остаётся только в `text`.
- `bookId` считается по названию, автору и подготовленному тексту/структуре.
  Word ID, диапазоны слов, статистика и имя EPUB в хэш не входят. При одинаковом
  подготовленном содержимом получается одинаковый ID. Изменение текста или
  разбиения предложений может изменить ID; ID старого Python-конвертера не обещается.
- `processing` фиксирует версию разметки. Используется локальная закреплённая
  библиотека SBD для английского и небольшой слой обработки диалогов.

### Извлечение текста

Документы читаются в порядке `spine` EPUB. Основные ориентиры для разделов —
ссылки оглавления EPUB 3 / EPUB 2 и уровни заголовков. Изображения, стили, скрипты
и навигация исключаются. Буквица, заданная изображением с однобуквенным `alt`,
сохраняется. HTML-пробелы схлопываются, текст нормализуется в Unicode NFC.
Жирное начертание, курсив, ссылки и исходная вёрстка не переносятся.

При неоднозначном разбиении на предложения конвертер сохраняет весь абзац одним
предложением и показывает замечание. Автоматическое определение границ предложений
может ошибаться; для просмотра разметки предназначены фрагменты JSON.

Если итоговый компактный JSON больше текущего лимита Worker 8 МиБ, инструмент
покажет замечание, но позволит скачать файл. При подключении такой книги нужно
будет согласовать размер пакета с загрузкой.

### Файлы инструмента

- `book-preparer.html` — интерфейс выбора EPUB и экспорта JSON.
- `book-preparer-core.js` — извлечение структуры, предложения, слова и `bookId`.
- `book-preparer.js` — состояние интерфейса, скачивание, копирование фрагмента.
- `vendor/` — локальные зависимости с лицензиями; сетевые загрузки не нужны.
