# Umbrello · English

Статическое приложение для занятий английским. При открытии любой страницы
Worker проверяет Telegram-аккаунт по `ALLOWED_USER_IDS`. После разрешения входа
главный экран показывает имена учеников и общие разделы **Listen**, **Books**
и **Grammar**, открытые всем разрешённым аккаунтам. В профиле ученика остаются
личные задания **Test** и **Write**. Профиль сохраняется в ссылке (`?user=sophia`
или `?user=me`), поэтому обновление страницы и переходы между разделами
не меняют ученика. Кнопка **Switch profile** открывает выбор имени.
Разрешённый Telegram-аккаунт может выбрать любое имя учебного профиля.
При отказе на любой странице показывается только бесконечная анимация зонтика —
без текста, ID и кнопок, — а владельцу приходит уведомление в бот с именем,
@username и Telegram ID. Новая проверка — закрыть и снова открыть Mini App.

## Папки

```text
index.html, test.html, write.html, listen.html, books.html, grammar.html — страницы приложения
assets/
  js/                    — логика страниц, профилей и настройки
  css/                   — оформление
users/
  index.json             — список пользователей
  sophia/
    test.json            — существующие тесты Sophia
  me/
    test.json            — задания на лексику C1–C2
listen/
  index.json             — общий список уроков Listen с уровнем сложности
  *.json                 — файлы уроков
tools/
  listen-time-getter.html — инструмент разметки видео
  book-preparer.html      — локальный EPUB → JSON v2 с ID слов и копированием фрагмента
  prepare-book.py        — локальная подготовка EPUB к чтению (book.json + preview.html)
  pyproject.toml, uv.lock — зависимости конвертера (uv)
worker/
  cf_worker.js           — Cloudflare Worker: отчёты, Write, приватные Grammar и Books
docs/
  WORKER.md              — единые переменные Worker, доступ и общий bucket
  WRITE.md               — подключение и устройство Write
  LISTEN.md              — инструкция по Listen
  GRAMMAR.md             — настройка приватного Grammar через Supabase
  BOOKS.md               — Books: подготовка, Storage, Worker и загрузка книг
tests/                   — автоматические проверки
```

Worker использует общие `ALLOWED_USER_IDS` и `SUPABASE_BUCKET` (`Umbrello`)
для всего приложения. Список разрешённых аккаунтов проверяется перед Books,
существующими запросами Grammar, Write и отправкой отчётов. Полный список
переменных и переход со старых имён — [docs/WORKER.md](docs/WORKER.md).

## Как добавлять материалы

Личные задания лежат в папке пользователя, общие разделы — в корне:

- **Test:** `users/<id>/test.json` — массив вопросов вида
  `{"q":"Question?","right":"Correct answer","wrong":["A","B","C"]}`.
  Пустой раздел: `[]`.
- **Write:** материалов нет, текст генерирует ИИ по запросу ученика.
- **Listen (общий):** положи JSON урока в `listen/` и добавь запись
  в `listen/index.json`:
  `{"id":"my-song","title":"My song","file":"my-song.json","level":"B1"}`.
  `level` — уровень сложности по CEFR (`A1`–`C2`); список уроков можно
  фильтровать по уровню, по умолчанию показаны все. Пустой раздел: `[]`.
  Формат урока описан в [инструкции Listen](docs/LISTEN.md).
- **Books и Grammar (общие):** материалы в приватном Supabase Storage,
  см. [docs/BOOKS.md](docs/BOOKS.md) и [docs/GRAMMAR.md](docs/GRAMMAR.md).

## Как добавить пользователя

1. Добавь в `users/index.json` запись
   `{"id":"alex","name":"Alex","level":"B1","reports":true}`.
   `id` должен быть уникальным: строчные латинские буквы, цифры и дефис.
   `level` — уровень ученика по CEFR (`A1`–`C2`): Write генерирует тексты
   и оценивает перевод под этот уровень. `reports` — отправлять ли результаты
   Test в бот. Оба поля необязательные: без `level` модель пишет как раньше,
   без `reports` отчёты отправляются.
2. Создай папку `users/alex/` с файлом `test.json` (`[]`).

Новый профиль появится автоматически. В отчёты Test включается имя
выбранного ученика; при `"reports": false` результат остаётся на экране ученика.

## Write

Тренажёр генерирует короткий украинский текст по твоему запросу и проверяет
английский перевод. Сложность текста и разбора задаёт `level` профиля
в `users/index.json`; уровень виден в строке задания. История и статистика не сохраняются; при обновлении страницы
упражнение исчезает. Для запросов нужны Telegram и настроенный OpenAI API в Worker.
Инструкция по подключению — [docs/WRITE.md](docs/WRITE.md).

## Grammar

Первый юнит: **Present continuous and present simple**. Learn содержит авторские
объяснения, Practice — 20 вопросов с CD, Listen — шесть заданий с оригинальным
аудио, Write — самостоятельный текст с проверкой, Review — пять новых вопросов.
Ответы и прогресс живут только в памяти открытой страницы.

Раздел общий для всех разрешённых аккаунтов и открывается с главного экрана.
Материалы загружаются из приватного Supabase Storage через Worker. Доступ
проверяется по подписанному Telegram ID, профиль для раздела не нужен.
Подготовленный пакет `private/grammar-upload/` исключён из Git и не публикуется
на Pages. Исходники раздела и авторские дополнения можно публиковать вместе
с остальным интерфейсом. Настройка и порядок загрузки — [docs/GRAMMAR.md](docs/GRAMMAR.md).

## Books

Новый инструмент подготовки: открой `tools/book-preparer.html` в браузере,
выбери EPUB и скачай JSON с разметкой слов. Он работает локально без Python
и позволяет скопировать отдельный абзац для обсуждения. Читалка принимает формат 2
с готовыми ID и диапазонами слов; описание — [tools/README.md](tools/README.md).

**Books** — общая библиотека и простая читалка готовых книг, открывается
с главного экрана без выбора профиля. Книги и каталог лежат в приватном
Supabase Storage и приходят через Worker только аккаунтам из `ALLOWED_USER_IDS`.

В Books страницы рассчитываются по экрану телефона, перелистывание — горизонтальным
свайпом. Длинные предложения продолжаются на следующем экране. Внизу показан номер
страницы внутри текущей главы. Оглавления и вертикальной прокрутки текста нет.
Место чтения сохраняется на телефоне и восстанавливается при следующем открытии.
Нажатие на слово открывает попап с коротким definition на английском для этого
предложения (фразовые глаголы распознаются целиком); ответ сохраняется
на устройстве, слово подчёркивается во всей книге, повторное нажатие не вызывает
ИИ, в попапе есть удаление. Подробности — [docs/BOOKS.md](docs/BOOKS.md).

Прежний Python-конвертер остаётся доступен (формат 1 тоже читается):

```sh
uv run --project tools tools/prepare-book.py input.epub --output output/my-book
```

Папка `output/` и файлы `*.epub` исключены из Git. Формат каталога, загрузка
и настройка Worker — [docs/BOOKS.md](docs/BOOKS.md).

## Локальный запуск и проверка

```sh
python3 -m http.server 8765 --bind 127.0.0.1
node --test tests/*.test.cjs
```

Открой `http://127.0.0.1:8765/`. Загрузка JSON требует HTTP;
открытие HTML двойным кликом через `file://` не подходит.

При публикации загружай страницы вместе с `assets/` и `users/`.
Если Telegram показывает старую версию, используй стартовую ссылку
`index.html?v=10` в настройках мини-приложения. Настройки бота находятся
вне этого репозитория.
