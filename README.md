# Umbrello · English

Статическое приложение для занятий английским. При открытии `index.html`
человек выбирает своё имя, затем Test, Read, Listen или Write. Профиль сохраняется
в ссылке (`?user=sophia` или `?user=me`), поэтому обновление страницы и переходы
между разделами не меняют ученика. В профиле **me** также доступен **Grammar**.
Кнопка **Switch profile** открывает выбор имени.
Это выбор профиля без пароля: любой посетитель может выбрать любое имя.

## Папки

```text
index.html, test.html, read.html, listen.html, write.html, grammar.html — страницы приложения
assets/
  js/                    — логика страниц, профилей и настройки
  css/                   — оформление
users/
  index.json             — список пользователей
  sophia/
    test.json            — существующие тесты Sophia
    read.json            — существующее чтение Sophia
    listen.json          — пока []
    listen/              — будущие уроки Listen для Sophia
  me/
    test.json            — задания на лексику C1–C2
    read.json            — пока null
    listen.json          — список существующих уроков Listen
    listen/              — файлы этих уроков
tools/
  listen-time-getter.html — инструмент разметки видео
worker/
  cf_worker.js           — Cloudflare Worker: отчёты, Write и приватный Grammar API
docs/
  WRITE.md               — подключение и устройство Write
  LISTEN.md              — инструкция по Listen
  GRAMMAR.md             — настройка приватного Grammar через Supabase
tests/                   — автоматические проверки
```

## Как добавлять материалы

Редактируй файлы только в папке нужного пользователя:

- **Test:** `test.json` — массив вопросов вида
  `{"q":"Question?","right":"Correct answer","wrong":["A","B","C"]}`.
  Пустой раздел: `[]`.
- **Read:** `read.json` — объект с `title`, массивом `sentences`
  (`{"en":"English sentence.","uk":"Переклад."}`), словарём `dict`
  и необязательным массивом `questions` в формате Test.
  Образец — файл Sophia. Пустой раздел: `null`.
- **Listen:** положи JSON урока в `listen/` нужного пользователя и добавь
  запись в его `listen.json`:
  `{"id":"my-song","title":"My song","file":"listen/my-song.json"}`.
  Путь `file` считается от папки пользователя. Пустой раздел: `[]`.
  Формат урока описан в [инструкции Listen](docs/LISTEN.md).

## Как добавить пользователя

1. Добавь в `users/index.json` запись `{"id":"alex","name":"Alex"}`.
   `id` должен быть уникальным: строчные латинские буквы, цифры и дефис.
2. Создай папку `users/alex/` с файлами `test.json` (`[]`),
   `read.json` (`null`) и `listen.json` (`[]`).
3. Для уроков Listen создай внутри папку `listen/`.

Новый профиль появится автоматически. Удалять файлы пустых разделов не нужно.
В отчёты Test и Read включается имя выбранного ученика.

## Write

Тренажёр генерирует короткий украинский текст по твоему запросу и проверяет
английский перевод. История и статистика не сохраняются; при обновлении страницы
упражнение исчезает. Для запросов нужны Telegram и настроенный OpenAI API в Worker.
Инструкция по подключению — [docs/WRITE.md](docs/WRITE.md).

## Grammar (me)

Первый юнит: **Present continuous and present simple**. Learn содержит авторские
объяснения, Practice — 20 вопросов с CD, Listen — шесть заданий с оригинальным
аудио, Write — самостоятельный текст с проверкой, Review — пять новых вопросов.
Ответы и прогресс живут только в памяти открытой страницы.

Материалы загружаются из приватного Supabase Storage через Worker. Доступ
проверяется по подписанному Telegram ID, а не по выбранному профилю.
Подготовленный пакет `private/grammar-upload/` исключён из Git и не публикуется
на Pages. Исходники раздела и авторские дополнения можно публиковать вместе
с остальным интерфейсом. Настройка и порядок загрузки — [docs/GRAMMAR.md](docs/GRAMMAR.md).

## Локальный запуск и проверка

```sh
python3 -m http.server 8765 --bind 127.0.0.1
node --test tests/*.test.cjs
```

Открой `http://127.0.0.1:8765/`. Загрузка JSON требует HTTP;
открытие HTML двойным кликом через `file://` не подходит.

При публикации загружай страницы вместе с `assets/` и `users/`.
Если Telegram показывает старую версию, используй стартовую ссылку
`index.html?v=7` в настройках мини-приложения. Настройки бота находятся
вне этого репозитория.
